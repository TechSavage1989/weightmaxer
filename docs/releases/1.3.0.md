## What's new

- Renamed the app to WeightMaxxer, including the Windows window, website and new Windows download
- Weigh-ins now update the remaining calorie schedule, daily macros and estimated goal date automatically
- Corrections, deleted entries and imported history recalculate the plan while keeping your chosen goal and original starting details
- Reaching or passing your goal shows maintenance instead of reversing the plan

Pace mode keeps your chosen weekly pace and updates the estimated completion date. Target date mode keeps your chosen deadline and recalculates from the remaining weight and time; calorie minimums still apply. The latest weigh-in dated from the plan start through today drives the forecast. Earlier and future entries remain in History.

New downloads use WeightMaxxer-win-x64.zip with WeightMaxxer.exe. The original Weightmaxer-win-x64.zip is also supplied so existing installations can update normally. Existing automatic updates keep the executable filename and shortcuts you already use. Saved data, the website address and the update feed stay compatible.

Install through the app's update banner, or download the new Windows package. The executable is not code-signed, so Windows SmartScreen may ask you to confirm the first start.
